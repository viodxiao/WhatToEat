# 今天吃什么，是啊吃什么

本地菜谱选择器。FastAPI 在启动时读取 `recipe` 下的 CSV、Markdown 和单向匹配规则，并为同一页面提供数据接口。前端无需额外构建。

## 本地运行

在 `InternetNewTec` 目录中执行以下命令。已有 `cook` 环境时可跳过创建步骤。

```powershell
conda create -n cook python=3.13 pip -y
conda run -n cook python -s -m pip install -r requirements.txt
conda run -n cook --no-capture-output python -s -m uvicorn scripts.main:app --host 127.0.0.1 --port 8000
```

打开 [菜谱选择器](http://127.0.0.1:8000/) 或 [接口文档](http://127.0.0.1:8000/docs)。在启动服务的终端按 Ctrl+C 可停止。修改菜谱数据后重启服务以重新读取。

## 筛选与用料

- 每次载入页面时，随机显示一组 CSV 标签。未选已有食材时，「菜谱」按难度、分类、佐料和厨具条件随机推荐最多五道菜，点击「换一批」可以刷新推荐。
- 在「菜谱」中输入菜名或部分关键词即可搜索全库。清空搜索框后返回当前厨房筛选。
- 厨房标签、难度、分类和菜单会保存在当前浏览器，刷新页面后自动恢复。
- 「菜谱分类」取自本地菜谱目录，支持多选。未选分类时包含所有菜谱分类。
- 绿色食材标签表示手头有，红色佐料和厨具标签表示手头缺。佐料和厨具筛选项来自 CSV 标签，未标记为缺少的佐料和厨具按可用处理。
- 只标记缺少的佐料或厨具时，搜索框与推荐菜谱之间会提示选择已有食材。选中已有食材后，会进一步核对食材是否齐全。
- 「食材已齐」要求每一组必需食材条件通过，且佐料、工具可用。Markdown 明确列出的可选条目不会阻挡匹配，同一组选一项即可。兼容关系沿本地规则的箭头扩展。
- 「还缺食材」显示与当前食材相关、但仍需补充食材的菜。只选土豆时，咖喱肥牛需要牛奶、肥牛等食材，香脆薯饼需要原文指定的预制薯饼。
- 点击带箭头的自制配料标签会加入右侧菜单，菜单上方汇总其已知原料。单道菜的用料清单保留原食谱给出的个数、体积、区间和按份公式。加入多道菜后，同名用料合并，全部有可加总的克数时才显示合计。源资料只有已知成分的配料会在详情中标明步骤未公布。
- 点击菜谱标题打开详情，旁边的加号将菜谱加入菜单。
- 在「所需材料」中点击「复制缺料清单」，即可复制未被现有食材满足的用料，以及明确标记缺少的佐料和厨具。浏览器无法写入剪贴板时会显示可手动复制的文本。

## 验证

```powershell
conda run -n cook python -s -m unittest scripts.test_planner -v
```

测试覆盖规则文件中的验收示例、食材与难度筛选、工具任选一项、可选项、配料与克数合并。
